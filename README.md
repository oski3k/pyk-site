# pyk-site

Publiczne strony aplikacji Pyk (GitHub Pages): polityka prywatności i instrukcja usuwania konta, po angielsku i po polsku.
Linkują do nich Google Play, App Store i sama aplikacja (Profil → Polityka prywatności). Kod aplikacji jest w prywatnym repo `oski3k/Pyk`, a tabela danych, z którą polityka musi się zgadzać, jest w `docs/PRIVACY.md` tamtego repo.

- https://oski3k.github.io/pyk-site/privacy.html (EN, adres w Play Console) · [privacy-pl.html](https://oski3k.github.io/pyk-site/privacy-pl.html) (PL)
- https://oski3k.github.io/pyk-site/delete-account.html (EN) · [delete-account-pl.html](https://oski3k.github.io/pyk-site/delete-account-pl.html) (PL)

Obie wersje językowe mają tę samą treść: zmieniaj je razem i aktualizuj datę „Obowiązuje od”.
